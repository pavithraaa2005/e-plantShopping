# e-plantShopping Project

## Paradise Nursery Shopping Application

**Repository Name:** e-plantShopping

### Project Overview
This application is the front-end for "Paradise Nursery," an online plant shop. It was built using React and Redux for state management. The application allows users to browse various categories of houseplants, view details, and manage a shopping cart.

### Key Features
- **Landing Page:** A welcoming interface with a background image and company description.
- **Product Listing:** Display of 6+ unique plants categorized into groups like Air Purifying and Aromatic plants.
- **Shopping Cart:** Real-time updates of total costs, ability to increase/decrease item quantities, and remove items.
